## Sicherheitsprobleme melden

Falls du eine Sicherheitslücke entdeckst, melde diese bitte wie folgt:

1. Erstelle **kein** öffentliches Issue
2. Sende eine E-Mail an: security@blackmarket-software.ch
3. Beschreibe das Problem so detailliert wie möglich
4. Wir werden innerhalb von 48 Stunden antworten

Bitte veröffentliche keine Details zur Schwachstelle, bis wir eine Lösung bereitgestellt haben.
